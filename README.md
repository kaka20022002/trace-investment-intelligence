# 溯知 Trace

**投资事件情报与证据时间线**。看清变化，回到证据。

一个可实际操作的 Web 产品：以投资事件为中心整理公告、报道、观点和传闻，辅助识别与合并同一事项，对照冲突，保留原文及四类时间，并在否认、更正和过期后重新计算当前判断。

> 默认预置 **6 个虚构事件、14 条模拟证据**。所有公司及 SIM 标识均为构造数据，不是真实上市公司、证券代码或实时金融资讯。不提供买卖建议、确定性涨跌预测或收益承诺。

## 快速运行

要求 Node.js 22+（本次验证为 Node.js 24.16.0）、npm、现代浏览器。

1. 在项目根目录运行 `npm ci`。
2. 运行 `npm run dev`。
3. 打开 http://localhost:5173 。不需要模型密钥即可体验完整主链路。

常用命令：

| 命令 | 功能 |
| --- | --- |
| `npm run dev` | 同时启动 Vite 前端 5173 和 API 服务 4173 |
| `npm run dev:web` | 仅前端，模型服务不可用时继续规则模式 |
| `npm run build` | 严格类型检查 + 生成 `dist/` |
| `npm start` | 服务端同时提供 `dist/` 页面与 `/api/`，先执行 build |
| `npm test` | 证据引擎、数据校验、模型代理等单元/接口测试 |
| `npm run test:e2e` | 桌面与移动端浏览器测试 |
| `npm run check` | 类型检查 + 单元/接口测试 |

端到端测试配置默认使用已安装的 Google Chrome。其他环境可安装 Chrome，或在 `playwright.config.ts` 移除 `channel: 'chrome'` 并使用 `npx playwright install chromium` 安装测试浏览器。移动端测试是 Chrome 的手机视口模拟，不代表已经覆盖真实 iOS Safari。

若本机 npm 全局缓存权限异常，可使用 `npm ci --cache .cache/npm`，无需修改系统目录权限。

## 90 秒体验路线

1. **情报工作台**：看到证据冲突、已否认、已证实、待核实、过期五种状态；按类型、状态、关键词筛选。
2. 打开**远川智造**：对照公告与报道的单季度/累计口径差异，点击“证据 1”回到原文和四类时间。
3. 回工作台，点击 **导入情报 → 填入演示案例 → 提取并匹配事件**。
4. 确认主体“澜芯科技”、事项“收购砺行半导体股权”、作用“更正”。
5. 在“明确替代的前版本”选择原来的澜芯科技否认公告，再确认归并。
6. 当前判断由**已否认 → 已证实**，但仅确认“签署意向书”，**不代表收购完成**；旧版显示“已被替代”，原文不删除。
7. 如果第 5 步不选择前版本，新旧相反陈述会保持**证据冲突**，不会因为更新较晚而盲目覆盖。
8. 关注事件、刷新验证持久化，到“数据与设置”导出 JSON 备份。工作台可导出含引用和时间的 Markdown 简报。

更详细的演示说明见 `docs/DEMO.md`。

## 产品能力

- **事件工作台**：搜索公司/标的/事件，状态和类型筛选，披露时间排序、证据数量排序、关注管理。
- **证据时间线**：按披露时间还原最早来源，查看作用、权重、过期和替代关系；支持证据对照表。
- **原文抽屉**：完整原文、逐字引用、发生/披露/抓取/更新时间、有效期、来源链接、转载来源链。
- **信息导入**：粘贴或导入 TXT/Markdown；规则/AI 辅助提取；人工修正字段；候选归并或创建新事件；保存后重新计算判断。
- **资料库与备份**：按属性/来源筛选证据，JSON 导出/校验恢复、重置前确认，损坏记录不静默覆盖。
- **状态透明**：未核验、无原文链接、发生时间未知、过期、模型失败均有明确提示。

## AI 的角色与环境变量

将 `.env.example` 复制为 `.env`，填写合法可用的模型服务配置后重启。

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `OPENAI_API_KEY` | 空 | 服务端模型密钥；空时不调用模型 |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | OpenAI-compatible 根地址，不含 `/chat/completions` |
| `OPENAI_MODEL` | `gpt-4o-mini` | 模型 ID；供应商需支持 chat completions 和 JSON object |
| `PORT` | `4173` | API / 生产页面服务端口 |
| `HOST` | `127.0.0.1` | 默认只允许本机连接；对外服务需配置网关和访问控制 |

- `GET /api/health`：只返回模式、模型名称和配置状态，不透露密钥，也不代表已验证供应商可用性。
- `POST /api/analyze`：输入 `content` 与至多 100 条事件参考，输出七字段提取结果。
- **AI 只做结构化整理**。最终状态由可解释规则计算，归并与关键字段由用户确认。
- 未配置时明确为**本地规则模式**，没有假装调用 AI。
- 失败/超时/非法 JSON/幻觉引用会返回结构化错误，前端提示并退回规则模式，不能静默伪装为成功。
- 规则模式原文留在浏览器；模型模式会将原文和事件参考发送到配置的供应商，请勿输入敏感信息。
- 服务端单进程按直连 IP 限流、同源约束、请求体上限、20 秒超时、远端响应大小限制、禁止跟随重定向。公开模型接口还需访问控制和全局额度管理。

## 证据规则

权重 = 来源基准 × 陈述属性系数 × 核验系数，四舍五入。

| 来源 | 公司公告 | 机构研报 | 财经媒体 | 社交平台 |
| --- | --- | --- | --- | --- |
| 基准 | 90 | 65 | 60 | 25 |

| 属性 | 事实 | 观点 | 推测 | 传闻 |
| --- | --- | --- | --- | --- |
| 系数 | 1 | 0.55 | 0.4 | 0.25 |

已人工核验系数 1，未核验 0.65。**来源核验为使用者声明，不是产品外部认证。权重不等于概率。**

- 只有有效、已核验、事实属性且权重 ≥ 60 的证据可以形成“已证实/已否认”。投资建议或收益保证性引用不进入事实确认。
- 有效强支持和强否认共存时显示“证据冲突”，即使同源也不会直接按最新一条覆盖。
- 明确同源、更晚披露的更正/更新/否认可替代前版本；原文保留。已核验事实不能被未核验材料通过版本关系撤销。
- 替代关系不会因新版本过期而复活旧版本。证据有效期截止后退出当前判断，页面每分钟重算并在导入后立即重算。
- 同一 `originId` 的转载只计一个独立来源，权重不叠加。去重保留小数点、正负号、百分号语义。
- 归并要求主体和类型一致，并比较事项键；明确不同年份、报告期拒绝归并。匹配分是启发式相似度而非概率，必须人工确认。
- 发生时间可缺失；披露/抓取/更新为必填 ISO 8601，页面按浏览器本地时区显示。手动导入时“抓取时间”指系统收到原文的时间，不声称已网络抓取。
- 统计卡片折线来自近 7 天本地记录与证据时点回放，**不是金融行情或虚构趋势**。

## 数据来源、边界与未做事项

- 预置数据：`src/seed.ts` 中人工构造的教育演示，包含冲突、否认、更正、过期和同源转载。
- 用户导入：用户提供原文与合法链接；浏览器不自动抓取任意网址，避免 SSRF 和不受控内容采集。
- 扶摇与 iFinD：未提供真实访问权限，界面如实显示未接入，没有伪造接口调用或外部源链接。
- 保存于本浏览器 `localStorage`，容量上限为 500 个事件 / 5000 条证据，入库及保存前校验。跨标签页通过写前快照校验和可用时的 Web Locks 防止静默覆盖；检测到其他页更新时暂停保存，需备份草稿后加载最新记录。不提供账号、多设备同步、后台调度、服务器数据库或多人协作。
- 自然语言提取与事项匹配并不具备通用语义正确率保证；复杂多事件原文、数值口径差异、未来计划与实际发生需要人工复核。当前冲突检测主要基于人工确认的支持/否认作用，不声称自动理解全部语义矛盾。
- 来源身份不做外部真实性背书，默认演示的核验标志仅是模拟。
- 不接行情、不做持仓、收益计算、交易操作或买卖建议。
- 实际外部模型与真实金融数据源未做端到端验证；自动化接口测试使用可控模拟响应，详细记录在 `docs/AI_USAGE.md`。
- 无远程自动发布、远程 Git 提交或可选视频成品；部署和演示脚本已准备。
