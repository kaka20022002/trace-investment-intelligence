# AI 使用与验证记录

记录日期：2026-10-11（本地时区）。本记录区分“开发过程使用 AI”与“产品运行时调用模型”，不将规则执行或模拟测试冒充真实模型效果。

## 1. 使用的工具与工作方式

- 在 CodeBuddy 的 AI 编码会话中完成需求分析、实现方案、React/TypeScript 前端、规则引擎与 Node 模型代理。
- 使用并行代码代理分别实现模型后端、编写证据引擎测试、进行只读缺陷审查。
- 使用 TypeScript 严格编译、Vitest 业务与接口测试、Playwright 真实 Chrome 浏览器自动化验证。
- 载入浏览器测试相关能力说明；实际验证使用项目内的 Playwright 测试代码，非声称人工点击已完成。
- 所有预置公司、事件、来源均为构造数据，没有访问或伪造真实扶摇/iFinD 数据接口。

## 3. 实际发现与修正

### A. 数值去重破坏财务语义

初版将所有标点与符号移除，导致 `1.5亿元` 与 `15亿元`、`+10%` 与 `-10%` 被判成同一原文。

修正：保留小数点、正负号、百分号等语义；只归一化常见排版差异，增加对应回归测试。

### B. 不同报告期被合并

初版按主体、类别、文字相似度匹配，会把第二季度与第三季度净利润误列为高分匹配。

修正：增加年份与报告期差异门槛；同公司同类型不等于同事项。匹配仍需人工确认，规则不声称具备通用语义完备性。

### C. 正式否认被分类为传闻

初版只看“传闻”关键词，将“公司公告：相关传闻不属实”错误降级。

修正：在明确公告/澄清语境中区分“否认行为”与“被否认的传闻”；保留原文校验和人工复核。名称本身仍不会自动核验来源真实性。

### D. 更正文本里的历史否认干扰当前作用

演示更正包含“此前未签署”，初版可能将其识别为再次否认。

修正：明确更正关系优先识别，人工选择同源旧版本后再替代；不选择旧版本时保留冲突。

### E. 同公司同类型直接套用旧事项键

初版规则提取可能只因公司相同就复用旧主题。

修正：只有明确事项或收购对象词匹配才复用；不同标的、不同类型和不同报告期加入负例测试。

### F. 装饰折线可能被理解为虚构趋势

初版统计卡片使用装饰性折线。

修正：改为从当前本地记录按历史时点计算近七天序列，提供明确非行情说明；不展示伪造涨跌或历史指标。

### G. 未核验信息借更正关系移除事实

修正：已核验、达到阈值的事实证据，只能被同源、已核验、达到阈值的事实版本替代。低权重信息可独立加入，但不能消除原证据。

### H. 建议与收益承诺污染事实结论

修正：含直接买卖建议、保证收益等表述的引用不进入事实确认，并提示被排除。该保守词法防护不是通用内容安全保证，公开生产环境仍需完整审核与访问控制。

### I. 独立复核后的完整性修正

- 否定更正：不能把所有“更正”视为正向支持；当前引用句的否定方向单独判断，正向演示中的历史否认不反向污染当前句。
- 来源链：用户明确填写的来源链优先，只有留空才继承前版本；跨来源链更正被明确阻止。
- 模型回退：先验证候选结果，再替换本地结果；幻觉引用失败后真正恢复规则字段，而不是只显示回退提示。
- 容量：500 个事件 / 5000 条证据的上限在入库和保存前校验，拒绝写入无法重新加载的记录。
- 跨标签页：写前核对加载快照，支持时使用浏览器 Web Locks 串行写入；收到其他页更新时暂停保存，保留本页草稿供备份并引导刷新。初始读取已有记录不会无意义重写。
- 为这些问题新增独立单元测试和桌面/手机浏览器回归，而非仅在文档中声称已处理。

### J. 运行和工程问题

- 本机 npm 默认缓存权限异常，使用工作区内独立缓存解决，没有修改系统目录所有权。
- 修复初版种子函数缺少闭合、未使用导入与配置类型问题。
- 通过移动端测试确认导航、弹窗、导入、下载和无页面级横向溢出。
- 提高正文与表单对比度和字号，非仅提交静态效果图。

## 4. 产品运行时 AI

### 模型模式

仅当后端配置合法模型服务后才启用。`POST /api/analyze` 将原文与最多 100 个事件参考作为不可信数据发给服务端指定的模型；要求输出公司、标题、类型、事项键、属性、作用、逐字引用七字段。

服务端校验：请求结构、返回 JSON、字段枚举和长度、原文逐字引用。拒绝不支持的引用、额外字段、异常响应、超时和过大输出。模型没有访问任意网址或执行工具的能力。合法结构仍不等于语义正确，必须人工确认。

### 规则模式

未配置模型或接口不可用时使用本地规则。界面明确标记本地规则与回退原因；没有生成虚构的 AI 调用记录、tokens 用量或模型置信度。

### 最终结论

来自纯函数证据规则，而不是模型“觉得可信”。分数是启发式权重，不是正确率或投资概率。原文、有效时间、来源核验声明和版本关系均可追溯。
