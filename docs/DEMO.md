# 90 秒产品演示路线

此文件是可选演示视频的操作脚本，不声称已经生成视频。

## 00–15 秒：看工作台

打开产品首页，展示事件跟踪、待核实、冲突和已证实统计。

说明：“这不是一页新闻列表。溯知把同一事件的不同版本连起来，每一个判断都可以回到证据。当前案例全部虚构。”

## 15–35 秒：核对冲突

点击远川智造事件，展示“证据冲突”。打开“证据对照”，指出单季度与前三季度累计口径不一致。

点击“证据 1”，展示完整原文与发生、披露、抓取、更新四类时间，再关闭抽屉。

说明：“不因为新报道更晚就覆盖原公告，也不把观点当事实；冲突留给使用者明确核验。”

## 35–65 秒：导入更正，更新结论

返回工作台 → 导入情报 → 填入演示案例 → 提取并匹配事件。

确认主体澜芯科技、事项收购砺行半导体股权、事实/更正。选择同源的原否认公告作为前版本，确认归并。

说明：“AI 或规则只辅助提取，归并需要人工确认。当前在未配置模型时明确使用本地规则。”

展示结论“已否认 → 已证实”，但只确认签署意向书；旧版标记“已被替代”，仍能打开原文。

## 65–80 秒：展示可追溯与风险边界

强调：“意向书不是交易完成，权重不是概率。过期材料会退出当前判断，转载不会重复提高权重。”

打开闻溪消费过期案例，或泊云软件更正金额案例作为补充。

## 80–90 秒：完成研究动作

回工作台导出简报，展示我的关注或数据设置中的 JSON 备份。

结尾：“让每一个判断都有迹可循。产品不提供涨跌预测、买卖建议或收益承诺。”

## 演示前准备

- 如需复现初始状态，在“数据与设置”先备份当前记录，再确认重置。
- 使用实际可访问的产品网页，不以 PPT、截图或讲稿替代交互。
- 录制时避免暴露环境变量、账号、真实持仓或个人材料。
